Global Skill Passport 

Build a working, modern, trustworthy web application called Global Skill Passport designed for skilled refugees and displaced professionals globally to prove their real competencies without relying on missing or unrecognized paper certificates—directly aligned with PLP's Track 1: Credential & Skills Validation (SDGs 4 & 8) and addressing displacement-related skill barriers (SDGs 10, 16 & 17).

Make it a complete, interactive, working application that loads with realistic sample profiles immediately and lets users generate and test new passports end-to-end with zero dead-end buttons:

1. Interactive Skill & Project Evaluator:

- Allows candidates to enter their name, current location/country, spoken languages, target role, project descriptions/case studies, and a GitHub repository or portfolio URL.

- Includes a one-click "Load Sample Profile" button (plus multiple sample profiles) so judges can test immediately.

- When submitted, runs a working evaluation that extracts core skills, estimates practical proficiency levels, highlights real-world strengths, and clearly separates Verified Evidence (analyzed project/repository details) from Self-Reported Claims (user-stated background/goals).

2. Global Skill Passport & Verification View:

- Generates a structured, employer-ready Skill Passport showing verified skills, highlighted projects, practical work readiness notes, a transparent verification/trust breakdown, and a working "Copy Passport Link" button with clear visual confirmation.

- Includes a clean Printable / Summary view option so candidates can easily share their proof of skills.

3. Employer & Partner Talent Explorer:

- Provides a search and filter view where hiring partners, mentors, or organizations can filter profiles by skill, target role, or language to connect vetted talent with real opportunities.

Use a clean, modern, accessible UI with intuitive navigation, responsive mobile layout, and smooth interactive feedback throughout.
