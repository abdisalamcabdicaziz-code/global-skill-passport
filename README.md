# Global Skill Passport

**"Skills speak when paperwork can’t."**

Global Skill Passport helps skilled refugees and displaced professionals prove real competencies through verifiable work—such as repositories, case studies, and delivered projects—when paper credentials, degrees, or records are missing or unrecognized. It separates **verified evidence** from **self-reported claims**, evaluates **compliance and payment readiness**, surfaces **bridging steps**, and connects opt-in candidates with opportunities.

## Key Features
- **Home & Impact Overview:** Live summary metrics across sample and created passports, four-step workflow, and clear separation between verified evidence and self-reported claims.
- **Create / Evaluator:** Submit projects, case studies, repository links, and compliance details to generate a Skill Passport.
- **Passport View:** Detailed breakdown of verified skills, highlighted projects, real-world strengths, compliance & payment readiness, bridging recommendations, and opt-in sharing controls.
- **Talent Explorer:** Search and filter shared candidate passports by verified skills, target role, language, location, and minimum evidence score, with shortlisting and introduction requests.
